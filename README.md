# kael. — Portfolio

Personal portfolio for Muhammad Haikal bin Ismail (kael.), solo product developer in Kuala Lumpur.

Vite + React + TypeScript + Tailwind CSS v4 + Lenis smooth scroll.

## Local dev

```bash
npm install
npm run dev
```

## Content

All site content lives in one file: `src/data/site.ts` — identity, contact details, and the three
showcase projects (Captura, Pretty Local KL, SimplePOS).

## Photo

Add your portrait at `public/images/haikal.webp` (portrait, ~4:5, ~85 KB). It renders in the About
section in grayscale and reveals color on hover.

## Deploy

Push to GitHub, import into Vercel. Build command `npm run build`, output directory `dist`.
